# 1.OutputParse组件及使用技巧
  为什么需要输出解析器:
  对于大语言模型输出的结果,我们可能仅需要对应的返回值,而不需要多余的内容,
  就需要对返回的内容进行结构化,格式化或解析.
  如果需要LLM理解你想要的格式,需要向其告知要输出的结构信息,
  当LLM进行推理并输出之后,需要按照和LLM约定的格式进行解析,从而形成了输出解析器.
  输出解析器=预设提示+解析功能
  
  输出解析器的使用场景:
  a.将非结构化的文本转换为结构化的数据
  b.截取部分文本
  c.自定义处理

  OutputParse输出解析器:
  LangChain中的输出解析器都实现了两个抽象方法:
  a.get_format_instructions 用于约定输出的格式,并转换为描述文本.
  b.parse 用来解析LLM的输出为约定的格式.
  输出解析器直接调用invoke来使用.
  API文档:https://reference.langchain.com/python/langchain_core/output_parsers/
  自定义解析器:继承于特定的解析器基类,并也重写上述两个抽象方法.

  其他思路参考:
  https://python.langchain.com/docs/how_to/#output-parsers
